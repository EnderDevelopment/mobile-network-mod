# Mobile Network Mod

Adds a mobile network system to Minecraft with smartphones, cellular towers, and more.

## Features

- Smartphone item with GUI
- Cellular tower block for network coverage
- Operator server block for network management
- Payment terminal block for transactions

## Requirements

- Minecraft 1.12.2
- Forge 14.23.5.2860

## Installation

1. Download the mod file.
2. Place it in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

1. Craft a smartphone using the recipe.
2. Place cellular towers to create network coverage.
3. Place an operator server to manage the network.
4. Use payment terminals for transactions.

## Configuration

The mod does not have a configuration file. All settings are hardcoded.
